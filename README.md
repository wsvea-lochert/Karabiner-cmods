# Karabiner-cmods
My complex modifications for Karabiner Elements.

## Mods

### caps-wasd
Hold Caps Lock + WASD for arrow keys. Caps Lock is repurposed as a modifier that maps W/A/S/D to Up/Left/Down/Right. Works with any additional modifiers (e.g. Shift+Caps+D to select text to the right).

### caps-backspace-delete
Hold Caps Lock + Backspace for forward delete. Useful on compact keyboards that lack a dedicated Delete key.

### super-space
Hold Caps Lock + Space to emit Shift+Control+Option+Command+Space (hyper key + space). This provides a global hotkey that won't conflict with any application shortcut.
